# CS180 Project 2: Fun with Filters and Frequencies

Webpage: https://yponvon.github.io/2/

## Folders

```
2/
├── index.html            the webpage
├── code/                 all my code (run from this folder)
│   ├── paths.py          where every script reads/writes images
│   ├── filters.py        the algorithms: convolution, Gaussians, unsharp mask,
│   │                     hybrid images, Gaussian/Laplacian stacks, blending
│   ├── part1.py          Part 1.1 – 1.3 (convolution timing, finite differences, DoG)
│   ├── bells_whistles.py Part 1 B&W: gradient orientation with a hand-written atan2
│   ├── part2_sharpen.py  Part 2.1 (unsharp mask + blur-then-sharpen evaluation)
│   ├── part2_hybrid.py   Part 2.2 (hybrids, Fourier analysis, color experiment)
│   └── part2_blend.py    Part 2.3 / 2.4 (stacks, oraple, Fig 3.42, eye-in-hand + cheetah-cat blends)
├── images/
│   ├── course/           provided by the course (not committed): taj, apple, orange,
│   │                     DerekPicture, nutmeg
│   ├── mine/             my own photos
│   ├── downloaded/       Wikimedia Commons images for 2.4 (credits on the webpage)
│   ├── results/          every figure the webpage shows (generated by the scripts)
│   └── unused/           photos I tried but didn't use (not committed)
└── starter_code/         the course's hybrid starter code (not committed)
```

Result filenames start with the part they belong to: `p11_`, `p12_`, `p13_` (Part 1),
`bw_` (Part 1 bells & whistles), `sh_` (2.1), `hy_` (2.2), `st_` (2.3), `bl_` (2.4).

## Running

```
pip install numpy scipy opencv-python scikit-image matplotlib
cd code
python part1.py
python bells_whistles.py
python part2_sharpen.py
python part2_hybrid.py
python part2_blend.py
```

Each script prints its numbers (timings, errors) and writes its figures to `images/results/`.
