# CS180 Project 4A: Image Warping and Mosaicing

Recovering homographies between photos, rectifying planar objects with inverse warping (nearest neighbor and
bilinear), and registering, warping and blending photos into mosaics.

Spec: https://cal-cs180.github.io/fa26/hw/proj3/partA.html
Webpage: https://yponvon.github.io/4/

## Folders

```
4/
```

Photos: `anthro_*` Anthropology & Art Practice building (3 photos), `sunshade_*` the concrete building with
sunshades (2 photos), `terrace_1` … `terrace_5` Chuk Wong Terrace (5 photos, left to right), `rect_map` campus
map sign, `rect_box` hand cream box.

## Running

```
pip install numpy opencv-python matplotlib
cd code
python main.py
```

All point files are already in `points/`, so `main.py` reproduces every result. Outputs go to
`images/results/`, named by part:

- `a2_<pair>_points.jpg` correspondences on both photos, `a2_<pair>_H.txt` the system of equations and H,
  `a2_summary.txt` fit errors and the leave-one-out test (all points vs only 4)
- `a3_<object>_input.jpg` / `_nn.jpg` / `_bilinear.jpg` / `_zoom.jpg` rectification with both interpolations
- `a4_<mosaic>_src*.jpg` source photos, `_overwrite.jpg` / `_average.jpg` / `_blend.jpg` the three blends,
  `_seam.jpg` seam close-up, `_weights.jpg` weight maps

Which photos make up each mosaic is set in `MOSAICS` at the top of `part4_mosaic.py`, and the rectangles with
their width:height in `RECTIFY` at the top of `part3_rectify.py`. The middle photo of each mosaic is the
reference; in the 5-photo terrace the outer photos are chained to it through their neighbours.

## Picking points

```
python pick_points.py <photo> <reference-side neighbour> <name>   # a mosaic pair, e.g.
python pick_points.py terrace_1.jpg terrace_2.jpg terrace_1_2
python pick_points.py <photo> <name>                              # a rectangle: 4 corners,
python pick_points.py rect_map.jpg rect_map                       # clockwise from top-left
```

Left click adds a point, right click removes the last one on that photo. Points are saved after every click;
press Enter or close the window to finish. Click the points in the same order on both photos. Running it again
on an existing name loads the saved points so they can be edited.

How the points were made: the `anthro_*` pairs were clicked by hand with `pick_points.py`. For the other pairs,
rough matches were placed on distinctive features and each was refined to the best-matching pixel by normalized
cross-correlation of small patches. The rectangle corners were placed by hand on zoomed-in crops.

numpy 2.0 on Mac prints harmless "divide by zero encountered in matmul" warnings; the results are fine.
