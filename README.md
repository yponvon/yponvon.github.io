# yponvon.github.io

My CS180 project website, hosted on GitHub Pages.

## How I built it

1. Took the photos for each part of Project 0 on my camera.
2. Sorted the photos into `0/media/` and picked which ones to use for each part.
3. Resized the photos down for the web using `sips` (built into macOS), so they'd load fast instead of being 15MB each.
4. Combined the dolly zoom stills into a looping GIF using `ffmpeg`.
5. Wrote a simple `0/index.html` with plain HTML/CSS, one section per part, photos shown side by side, a short paragraph under each explaining what I did.
