# yponvon.github.io

My CS180 (Intro to Computer Vision and Computational Photography) project website, hosted on GitHub Pages.

**Live site:** https://yponvon.github.io/

| Project | Page |
|---|---|
| Project 0: Becoming Friends with Your Camera | https://yponvon.github.io/0/ |
| Project 1: Images of the Russian Empire | https://yponvon.github.io/1/ |
| Project 2: Fun with Filters and Frequencies | https://yponvon.github.io/2/ |

## Folders

```
yponvon.github.io/
├── index.html        front page with a card for each project
├── assets/           shared by every page
│   ├── blog.css      the look: background, cards, fonts, figures
│   ├── blog.js       contents sidebar, current-section highlight, click-to-zoom images
│   └── background.jpg
├── 0/                Project 0
│   ├── index.html
│   └── images/
│       ├── raw/      original camera photos
│       └── results/  resized photos and the dolly zoom GIF shown on the page
├── 1/                Project 1 (see 1/README.md)
│   ├── index.html
│   ├── code/         alignment code
│   └── images/results/
└── 2/                Project 2 (see 2/README.md)
    ├── index.html
    ├── code/         filters, hybrids, stacks and blending (run code/main.py)
    └── images/       inputs (mine, downloaded) and results/
```

Course-provided data and scratch outputs (`*/images/course/`, `1/images/output/`, `2/images/unused/`, starter code)
are listed in `.gitignore` and are not committed.

## How the pages are built

- Every project page is plain HTML that links `assets/blog.css` and `assets/blog.js`, so a style change there
  updates all pages at once.
- Each page is split into parts (`<h2>`) and subsections (`<h3>`); `blog.js` builds the contents sidebar from those
  headings automatically.
- The figures on each page come from that project's `images/results/` folder. For Projects 1 and 2 they are
  generated by the code in `code/`.

### Project 0

1. Took the photos for each part on my camera (`0/images/raw/`).
2. Resized them for the web with `sips` (built into macOS) so they load fast instead of being 15 MB each.
3. Combined the dolly zoom stills into a looping GIF with `ffmpeg`.

### Projects 1 and 2

Run the code in each project's `code/` folder to regenerate the figures in `images/results/`
(details in `1/README.md` and `2/README.md`).

## Viewing locally

Open `index.html` in a browser, or run a small server from the repo root:

```
python3 -m http.server
```

then go to http://localhost:8000.
