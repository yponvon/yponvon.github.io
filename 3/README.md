# CS180 Project 3: Flow Models

Part A: Exploring the Power of Flow Models (a pretrained text-to-image model).
Part B: Flow Matching from Scratch (UNets trained on MNIST).

Webpage (both parts): https://yponvon.github.io/3/

## Folders

```
3/
├── index.html              the webpage
├── parta_updated.ipynb     Part A course notebook with my implementations (run on Colab/Kaggle with a GPU)
├── partb.ipynb             Part B course notebook with my UNets, training and sampling (same)
├── code/
│   └── collect_results.py  turns either notebook's results zip into the images the webpage uses
├── content/                my input images, uploaded to Colab's /content/ (not committed)
└── images/
    ├── raw/                the notebook's results folder, unzipped (not committed)
    └── results/            every image the webpage shows (generated by collect_results.py)
```

Input images (`content/`): `my_image_1` Eiffel Tower and `my_image_2` Sacré-Cœur (my photos), `web_image` a macaw
from the web, `drawing_1` / `drawing_2` my drawings of Gojo Satoru and Anya Forger.

Result filenames start with the section they belong to. Part A: `p11_` … `p16_`, `p21_`, `p31_` … `p34_`.
Part B: `b12_` … `b123_`, `b22_` … `b26_`. Part B only uses MNIST, which the notebook downloads itself.

## Running Part B

Open `partb.ipynb` in Colab or Kaggle with a GPU and run all (no uploads needed). The last cell zips the
figures and `metrics.json`. Then `python code/collect_results.py ~/Downloads/all.zip`.

## Running Part A

1. Open `parta_updated.ipynb` in Colab (Runtime → Change runtime type → GPU) or Kaggle (GPU, Internet on).
2. Upload the five images from `content/` (Colab: Files sidebar, they land in `/content/`; Kaggle: add them as a
   dataset, the notebook finds them by name).
3. Run all. The last cell zips the results folder and downloads it.
4. Back here:

```
pip install pillow
python code/collect_results.py ~/Downloads/<run-name>.zip
```

This writes `images/results/` and prints the numbers the webpage quotes (best blur σ, reconstruction MSEs).
